#Movie Explorer App

A React-based movie and TV show application that allows users to browse, search, and view detailed information about movies and TV shows using the TMDB API. The app also includes Firebase authentication and a personal watchlist feature.

#Features

- Search movies and TV shows
- View detailed movie/TV information
-Display cast, genres, and overview
- Watch trailers using YouTube embed
- Add and remove movies from watchlist
- Watchlist stored using Firebase Firestore
- User authentication (login/signup/logout)
- Streaming platform availability (where supported)
- Fully responsive design

#Tech Stack
- React.js (Functional Components, Hooks)
- React Router DOM
- Firebase (Authentication and Firestore)
- TMDB API
J- avaScript (ES6+)
- CSS3
