🎬 Movie Explorer App

A modern React-based Movie & TV Show discovery app powered by TMDB API and Firebase, where users can browse movies, view details, watch trailers, and manage a personal watchlist.

# Features
-Search movies & TV shows in real-time
-Detailed movie/TV pages (cast, trailer, genres, overview)
-Add/remove movies to Watchlist
-Streaming platform availability (Netflix, Prime, etc.)
-Top cast with horizontal scroll UI
-Embedded YouTube trailers
-Firebase authentication (login/signup/logout)
-Watchlist stored in Firestore
 -Fully responsive UI (mobile + desktop)

# Tech Stack
 -React.js (Hooks + Functional Components)
 -React Router DOM
 -Firebase (Auth + Firestore)
 -TMDB API (Movies & TV data)
 -CSS3 (Custom styling, responsive design)
 -JavaScript (ES6+)
